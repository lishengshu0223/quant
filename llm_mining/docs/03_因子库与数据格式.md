# 03 · 因子库与数据格式

> 本文档说明模块产生的全部**持久化数据**的格式与读取方法，供人/AI 快速读懂"当前挖掘进行到哪了、库里有什么"。
> 目录总览见 [README.md](../README.md#2-目录结构)。

## 1. 因子库根目录 `local_miner/factor_library/`

```
factor_library/
├── success/          # 成功因子库：每个合格因子一个文件夹（三件套）
└── failed/           # 失败因子库：每个战役一个文件夹
```

- 写入方：`factor_library.py` / `factor_archive.py` / `failed_library.py`。
- 读取方：挖掘注入（`library_summary_text` / `injection_text`）、相关性检查、编排器 `qualified_count` 等。

## 2. 成功因子库 `success/<series_id>_<name>/`

**系列编号**：`D`=日频（D001、D002...）、`M`=分钟（M001、M002...），两个前缀独立计数。
一个「系列」= 围绕同一核心逻辑的整条迭代路径，`best` 为该系列当前最佳因子。

### 三件套

| 文件 | 格式 | 内容 |
|---|---|---|
| `<id>_<name>.json` | JSON | 结构化因子信息 + 回测摘要（见下） |
| `<id>_<name>_backtest.h5` | HDF5 | 完整回测宽表（float32 + zlib gzip），可重放任意回测/图表 |
| `<id>_<name>_回测评价.png` | PNG | 因子评价图（标注合格） |

### 系列 json 字段说明

| 字段 | 说明 |
|---|---|
| `series_id` | 系列 ID（F/M 前缀） |
| `name` / `desc` / `style` | 因子名 / 经济含义简介 / 风格大类标签 |
| `status` | `qualified`（入库即合格） |
| `created_at` / `updated_at` | 创建/更新时间 |
| `best` | 当前最佳因子：`{name, desc, expr, style, hypothesis, eval, diagnostics}` |
| `best.eval` | 完整结构化评价（见下节） |
| `best.diagnostics` | 三项诊断：`turnover_cost` / `monotonicity` / `stress` |
| `path` | 整条迭代路径：`[{round, name, expr, style, hypothesis, qualified, eval}, ...]` |
| `hypotheses_tried` | 尝试过的假设（最近 30 条） |
| `lessons_success` / `lessons_failure` | 成败经验归纳（各限长） |

### `best.eval` 关键字段

| 字段 | 含义 |
|---|---|
| `ic_mean` / `ic_std` / `icir` | 5 日 RankIC 均值 / 标准差 / ICIR |
| `long_total` / `long_annual` | 多头累计超额（日度等效）/ 多头年化超额 |
| `monthly_pos_ratio` / `neg_months` | 月度 IC 正占比 / 为负的月份列表 |
| `yearly_long` / `bad_hist_years` | 分年度多头超额 / 为负的历史完整年份（`latest_year` 最新年份豁免） |
| `group_annual` | 各分组年化收益（Q1~Q10） |
| `group_monotonicity` | 单调性指标：`daily_rank_corr`（每日秩相关均值+分年度）、`daily_out_of_order`（越序惩罚日均+分年度）、`yearly_out_of_order`（年度聚合越序） |
| `monotonicity_grade` | 四级评级 `{grade: S/A/B/C, drc, doo, yearly_peak, grade_rank, grade_oos, grade_peak, neg_years, bad_years}` |
| `long_stability` | 多头年度稳定性：`{score=yearly_ir, mean, std, cv, hhi, min_year, min_year_year, n_years}` |
| `flipped` | 评价时是否已自动取反翻转方向 |
| `qualified` | 是否合格 |
| `review_rejected` / `library_rejected` | 入库被拒标记（含 `review_reason` / `library_max_corr`） |

### h5 读取方法

```python
from llm_mining.local_miner.factor_archive import load_backtest_h5
import glob
path = glob.glob(r"F:\quant\llm_mining\local_miner\factor_library\success\*\*_backtest.h5")[0]
df = load_backtest_h5(path)   # DataFrame: 日期索引 × 股票列
```

## 3. 失败因子库 `failed/<campaign_key>/`

**campaign_key = `<frequency>_<eval_start_date>`**（如 `daily_20180101`、`minute_20180101`），一次战役一个文件夹。

| 文件 | 内容 |
|---|---|
| `round_XXX.json` | 该轮全部因子的精简记录：`{round, hypothesis, reflection, factors:[{name, expr, style, reason, detail, ic_mean, long_total, monthly_pos_ratio, grade, neg_years}]}` |
| `round_XXX_summary.json` | 该轮一句话失败总结：`{round, n_factors, n_failed, reasons:{原因:次数}, text}` |
| `campaign_summary.json` | 战役级总结：`{campaign, frequency, rounds, adopted, stats, rule_text, llm_summary, llm_ok, created_at}` |
| `index.json` | 注入索引：最近 4 个战役的 `{campaign, ts, frequency, summary_text}`（供首轮注入） |

**失败原因分类**（`failed_library.failure_reason`，顺序即判定优先级）：

`计算失败` → `合格`（不计失败）→ `语义评审拒绝` → `相关性撞车` → `方向无效` → `单调性C级` → `月度不足` → `年度为负` → `其他未达标`。

## 4. 工作区 `local_miner/workspace/`（过程性，可清空）

| 文件 | 内容 |
|---|---|
| `checkpoint_new.json` / `checkpoint_new_minute.json` | new 模式检查点（日频/分钟） |
| `checkpoint_optimize_<series>.json` | optimize 模式检查点 |
| `mining_new.log` / `mining_new_minute.log` / `mining_optimize_<series>.log` | 各模式运行日志（终端双写） |
| `mining_loop_state.json` / `mining_loop.log` / `mining_loop.pid` | 编排器状态 / 日志 / 单实例 PID |
| `campaign_summaries.json` | 历史战役压缩摘要（保留最近 3 次，首轮注入） |
| `factor_report_*.png` | 采纳/最终因子报告图（按系列+轮次命名，不覆盖历史） |

**检查点 state 结构**：

```json
{
  "config": {...}, "mode": "new|optimize", "series_id": "",
  "round": 0, "stage": "init|model_called|round_done",
  "history": [{"round", "hypothesis", "reflection", "factors": [...]}],
  "pending": {"round", "parsed", "raw", "model"},   // 模型已输出未评价
  "best": null, "hidden_combos": [...], "combo_exhausted": false,
  "rejected_mem": {"items": [...], "max_items": 60, "dropped": 0},
  "campaign_adopted": ["D001", ...]
}
```

## 5. 成果输出目录 `output/<YYYYMMDD>_<任务名>/`（分析成果，保留）

| 文件 | 内容 |
|---|---|
| `roundXXX_fYY_<name>.png` | 每轮每因子评价图 |
| `library_corr_matrix.png` / `.csv` | 全库合格因子相关性热图/矩阵 |
| `index.html` | 静态 HTML 进度报告（KaTeX 公式 + 评价图 + 相关性），可浏览器直接打开 |

任务名：日频=「因子挖掘」，分钟=「分钟因子挖掘」；`--output-dir` 可覆盖。

## 7. 常见读取场景速查

| 需求 | 做法 |
|---|---|
| 库里有几个合格因子 / 各是什么 | `factor_library.load_library()` 或读 `success/*/F*/M*.json` |
| 某个系列当前最佳公式与评价 | 读该系列 json 的 `best.expr` / `best.eval` |
| 挖掘进行到第几轮 | 读检查点 `round` 字段 |
| 最近一轮失败了什么 | 读失败库最新 `round_XXX.json` 的 `reason` |
| 最近战役总结 | 读失败库 `campaign_summary.json` 的 `llm_summary` / `rule_text` |
| 历史战役经验 | 读 `workspace/campaign_summaries.json` |
